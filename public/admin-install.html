Install Admin Portal

Add the Admin Portal to your Home Screen using the icon shown above.

  1. In Safari, tap Share.
  2. Choose Add to Home Screen. Keep Open as Web App enabled if shown.
  3. Check the Admin icon and name, then tap Add.

If you previously installed an icon that opens the public website, remove that Home Screen icon and add this one again.

In Chrome or Edge, use the browser menu to install this app.
