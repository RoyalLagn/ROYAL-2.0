Install RoyalLagn Vendor

Add RoyalLagn to your Home Screen and open it like an app. No app store needed.

Open RoyalLagn Vendor

Android or desktop

Tap Install App when available. Otherwise, open Chrome or Edge’s menu and choose Install app or Add to Home screen.

Safari

  1. Tap Share.
  2. Choose Add to Home Screen. Keep Open as Web App enabled if shown.
  3. Tap Add.

Your vendor workspace opens after sign-in.
